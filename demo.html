Lightkeeper

Read-only glucose displays for e-ink screens, bedside clocks, and iOS, fed from a self-hosted Nightscout site. Built for one household first, shared with the type 1 open source community.

Everything on this page is simulated in your browser with made-up readings. The real tool needs a Nightscout site and a read-only token (see the README). It is a secondary display, not a medical device: always confirm on the primary CGM app.

Three promises

01 · Rules
  • Never shows old data as current Readings older than 15 minutes, or dated in the future, show as STALE - DO NOT TRUST.
  • Fails visibly, not silently If Nightscout goes down, the last value ages into STALE instead of freezing on screen.
  • Read-only by design It never talks to the pump or sensor. Dosing stays in Trio.

Colophon

        
The panel is drawn in Keeper 5x8, a pixel font drawn for this project, by an integer-only port of the panel layout, so it matches the Python reference pixel for pixel for every state at all six panel sizes. The words are set in your system's own fonts (IBM Plex or Bricolage Grotesque only if you already have them); no font files ship.
