# Support

Lightkeeper is a secondary display and not a medical device. For anything about insulin, dosing, or sensor behavior, talk to your care team or the primary app's support.

## Project questions

- Read the wiki first: https://github.com/esanacore/lightkeeper/wiki
- Common problems: `docs/TROUBLESHOOTING.md`
- Open an issue for bugs or feature requests: https://github.com/esanacore/lightkeeper/issues. Use the templates; never include real glucose data, Nightscout URLs, or tokens.
- Security problems: see `.github/SECURITY.md` for private reporting.

## Questions about the rest of the stack

- Nightscout: https://nightscout.github.io
- Trio: https://triodocs.org and the Trio community channels linked there
- Omnipod 5 with open source apps: https://nightscout.github.io/omnipod-five

## Response expectations

This is a volunteer project. Issues are triaged within a week; safety reports are looked at as soon as they are seen.
